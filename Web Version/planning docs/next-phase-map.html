North Star

Product Shape

CoNES Studio becomes a local-first browser IDE for CoNES. Users can open or write .cnes, run the solver, lint input, inspect structured results, and read targeted docs without sending solve work to a server.

Technical Shape

The browser app is a static Vercel deployment. React owns interface state and composition. The accepted Packet 002 worker owns execution, runtime data mounting, stdout/stderr capture, and the existing --json contract.

Stack Decision

Layer Decision Reason
App shell Vite + React + TypeScript Static build output, fast local feedback, clear component boundaries, and no server framework assumptions.
Styling Tailwind CSS v4 Token-based interface styling that pairs with shadcn/ui and avoids bespoke CSS for normal app controls.
Components shadcn/ui Source-owned components for tabs, sidebar, dialogs, forms, tables, alerts, command palette, and resizable panes.
Icons lucide-react unless shadcn project context selects otherwise Matches existing guidance and provides tool/IDE icon coverage without hand-drawn SVG controls.
Editor Monaco after runner migration Best fit for an IDE-like text surface, diagnostics, and future completion work.
Terminal/CLI view xterm.js when interactive CLI affordances are needed Keep raw stdout/stderr simple first; add terminal affordances only when the workflow needs them.

Application Map

Workbench

Edit the active .cnes buffer in Monaco, rename it, lint it, run it, and save it.

Results

Show structured --json output and offer a JSON download.

Diagnostics

Run manual and debounced lint with line-level Monaco markers.

Debug surfaces

Tools, Docs, Workspace, raw output, and runtime internals stay hidden unless the hard-coded debug flag is enabled.

Guardrails

Carry forward

Preserve raw stdout/stderr, the downloadable JSON contract, static /runtime and /runtime-data paths, manifest byte/sha256 checks, and thisProgram: "/app/cnes".

Do not introduce

No Next.js, Prisma, auth, server actions, Railway, Redis, backend solve API, or casual C++ core rewrite. The web app packages and exposes the accepted CoNES runtime.
