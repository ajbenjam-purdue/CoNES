Packet 007 Companion

IDE Workbench Implementation Guide

This is the opinionated build companion for Packet 007. It names the concrete files, dependencies, components, helper shapes, and code blocks that should turn the current Editor, Runner, Runtime, and Results surfaces into one Monaco-backed workbench loop.

Draft for implementation Monaco required Reuse worker client Reuse ResultsViewer No backend No runtime contract rewrite

Build Principle

One Loop

The workbench should make one loop obvious: edit source in Monaco, run the current buffer, inspect structured results, inspect raw stdout/stderr, then save or download artifacts.

Small Runtime Change

Do not change the worker protocol. Add a small runSource helper to the client that turns editor text into a File and delegates to the existing run(file) method.

Implementation Order

  1. Add Monaco dependencies and verify the app still builds.
  2. Add runSource to src/features/runtime/worker-client.ts.
  3. Create src/features/workbench with source state, Monaco editor, run panel, and output panel.
  4. Wire a new Workbench route beside Runner, not in place of Runner.
  5. Add browser smoke coverage for edit-run-results from the workbench.
  6. Run local verification, deploy, then run hosted smoke against the Vercel public URL.

Runtime Client Addition

Add this helper to src/features/runtime/worker-client.ts. It preserves the existing run(file) path and the worker still receives a normal run message with argv: [...runArgv]. 

type SourceRunInput = {
  fileName: string;
  contents: string;
  lastModified?: number;
};

async runSource(
  input: SourceRunInput,
  options: { onStatus?: (message: WorkerStatusMessage) => void } = {},
) {
  const fileName = normalizeCnesFileName(input.fileName);
  const file = new File([input.contents], fileName, {
    type: "text/plain;charset=utf-8",
    lastModified: input.lastModified ?? Date.now(),
  });

  return this.run(file, options);
}

Add the helper near the bottom of the same file, outside the class. 

function normalizeCnesFileName(fileName: string) {
  const trimmed = fileName.trim() || "untitled.cnes";
  return trimmed.toLowerCase().endsWith(".cnes") ? trimmed : `${trimmed}.cnes`;
}

Workbench Source State

Create src/features/workbench/workbench-source-state.ts. Keep this hook browser-local and explicit. No localStorage, IndexedDB, multi-file projects, or implicit autosave in Packet 007. 

import { useMemo, useRef, useState } from "react";

const defaultSource = `# New CoNES file
h = 100 W/m^2*K
A_c = 0.5 m^2
T_fluid = 20 C
Q = 1 kW

Q = h * A_c * (T_surface - T_fluid)
`;

type SourceMeta = {
  fileName: string;
  loadedText: string;
  source: string;
  lastModified: number | null;
};

export function useWorkbenchSource() {
  const inputRef = useRef<HTMLInputElement | null>(null);
  const [meta, setMeta] = useState<SourceMeta>({
    fileName: "untitled.cnes",
    loadedText: defaultSource,
    source: defaultSource,
    lastModified: null,
  });
  const [error, setError] = useState<string | null>(null);

  const dirty = meta.source !== meta.loadedText;
  const stats = useMemo(() => ({
    characters: meta.source.length,
    lines: meta.source.length === 0 ? 0 : meta.source.split(/\r\n|\r|\n/).length,
  }), [meta.source]);

  async function openFile(file: File | null) {
    setError(null);
    if (!file) return;
    if (!file.name.toLowerCase().endsWith(".cnes")) {
      setError(`${file.name} is not a .cnes file`);
      if (inputRef.current) inputRef.current.value = "";
      return;
    }

    const source = await file.text();
    setMeta({
      fileName: file.name,
      loadedText: source,
      source,
      lastModified: file.lastModified || null,
    });
  }

  function setSource(source: string) {
    setMeta((current) => ({ ...current, source }));
  }

  function newDraft() {
    setMeta({
      fileName: "untitled.cnes",
      loadedText: defaultSource,
      source: defaultSource,
      lastModified: null,
    });
    setError(null);
    if (inputRef.current) inputRef.current.value = "";
  }

  function markSaved() {
    setMeta((current) => ({ ...current, loadedText: current.source }));
  }

  return {
    inputRef,
    source: meta.source,
    fileName: meta.fileName,
    lastModified: meta.lastModified,
    dirty,
    stats,
    error,
    openFile,
    setSource,
    newDraft,
    markSaved,
  };
}

Create src/features/workbench/monaco-cnes-language.ts. Keep it lightweight: language id, comments, and basic tokens. No diagnostics or completion providers yet. 

import type * as Monaco from "monaco-editor";

let registered = false;

export function registerCnesLanguage(monaco: typeof Monaco) {
  if (registered) return;
  registered = true;

  monaco.languages.register({
    id: "cnes",
    extensions: [".cnes"],
    aliases: ["CoNES", "cones"],
  });

  monaco.languages.setLanguageConfiguration("cnes", {
    comments: { lineComment: "#" },
    brackets: [["(", ")"], ["[", "]"]],
    autoClosingPairs: [
      { open: "(", close: ")" },
      { open: "[", close: "]" },
      { open: '"', close: '"' },
    ],
  });

  monaco.languages.setMonarchTokensProvider("cnes", {
    tokenizer: {
      root: [
        [/#.*$/, "comment"],
        [/"[^"]*"/, "string"],
        [/\b\d+(\.\d+)?\b/, "number"],
        [/[+\-*/=()]/, "operator"],
        [/[A-Za-z_][\w.]*/, "identifier"],
      ],
    },
  });
}

Workbench Page Shape

Create src/features/workbench/WorkbenchPage.tsx. It should compose the existing worker client, prewarm state, ResultsViewer, and RunnerOutput. This is the core integration surface. 

import { useEffect, useRef, useState } from "react";
import { Download, FilePlus2, Play, Upload } from "lucide-react";
import { Button } from "@/components/ui/button";
import { Badge } from "@/components/ui/badge";
import { getRuntimeWorkerClient, subscribeRuntimePrewarm, getRuntimePrewarmState } from "@/features/runtime/runtime-prewarm";
import type { RuntimePrewarmState } from "@/features/runtime/runtime-prewarm";
import type { WorkerRunResult } from "@/features/runtime/worker-contract";
import { RunnerOutput } from "@/features/runner/RunnerOutput";
import { ResultsViewer } from "@/features/results/ResultsViewer";
import { MonacoSourceEditor } from "@/features/workbench/MonacoSourceEditor";
import { useWorkbenchSource } from "@/features/workbench/workbench-source-state";

export function WorkbenchPage() {
  const source = useWorkbenchSource();
  const clientRef = useRef(getRuntimeWorkerClient());
  const runTokenRef = useRef(0);
  const [prewarmState, setPrewarmState] = useState<RuntimePrewarmState>(() => getRuntimePrewarmState());
  const [isRunning, setIsRunning] = useState(false);
  const [result, setResult] = useState<WorkerRunResult | null>(null);
  const [workerLabel, setWorkerLabel] = useState(prewarmState.label);
  const [downloadUrl, setDownloadUrl] = useState("");

  useEffect(() => subscribeRuntimePrewarm(setPrewarmState), []);
  useEffect(() => {
    if (!isRunning) setWorkerLabel(prewarmState.label);
  }, [isRunning, prewarmState.label]);

  useEffect(() => {
    const blob = new Blob([source.source], { type: "text/plain;charset=utf-8" });
    const url = URL.createObjectURL(blob);
    setDownloadUrl(url);

    return () => URL.revokeObjectURL(url);
  }, [source.source]);

  async function handleRun() {
    if (isRunning) return;

    const activeToken = ++runTokenRef.current;
    setIsRunning(true);
    setResult(null);
    setWorkerLabel(prewarmState.status === "ready" ? "Running" : "Preparing runtime");

    const nextResult = await clientRef.current.runSource({
      fileName: source.fileName,
      contents: source.source,
      lastModified: source.lastModified ?? undefined,
    }, {
      onStatus: (message) => setWorkerLabel(message.phase || "running"),
    });

    if (activeToken !== runTokenRef.current) return;
    setIsRunning(false);
    setWorkerLabel(nextResult.type === "success" ? "Complete" : nextResult.error?.code || "Failed");
    setResult(nextResult);
  }

  return (
    <section className="grid min-h-[calc(100svh-4rem)] grid-cols-[minmax(0,1fr)_420px] max-xl:grid-cols-1" data-workbench-page>
      <main className="flex min-w-0 flex-col">
        <header className="flex flex-wrap items-center justify-between gap-3 border-b p-4">
          <div className="min-w-0">
            <div className="mb-2 flex flex-wrap items-center gap-2">
              <Badge variant="secondary">Workbench</Badge>
              <Badge variant={source.dirty ? "outline" : "secondary"}>{source.dirty ? "Unsaved changes" : "Clean"}</Badge>
              <Badge variant="outline">{workerLabel}</Badge>
            </div>
            <h2 className="truncate text-xl font-semibold tracking-normal">{source.fileName}</h2>
          </div>

          <div className="flex flex-wrap gap-2">
            <Button type="button" variant="outline" onClick={source.newDraft}><FilePlus2 /> New</Button>
            <Button asChild type="button" variant="outline">
              <label className="cursor-pointer">
                <Upload /> Open
                <input ref={source.inputRef} className="sr-only" type="file" accept=".cnes" onChange={(event) => void source.openFile(event.target.files?.[0] ?? null)} />
              </label>
            </Button>
            <Button asChild type="button" variant="outline">
              <a href={downloadUrl} download={source.fileName} onClick={source.markSaved}><Download /> Save</a>
            </Button>
            <Button type="button" onClick={handleRun} disabled={isRunning || source.source.trim().length === 0} data-workbench-run-button>
              <Play /> {isRunning ? "Running" : "Run"}
            </Button>
          </div>
        </header>

        <MonacoSourceEditor value={source.source} onChange={source.setSource} readOnly={isRunning} />
      </main>

      <aside className="min-w-0 border-l bg-muted/30 max-xl:border-l-0 max-xl:border-t">
        <ResultsViewer stdout={result?.stdout || ""} stderr={result?.stderr || ""} isRunning={isRunning} />
        <RunnerOutput stdout={result?.stdout || ""} stderr={result?.stderr || ""} />
      </aside>
    </section>
  );
}

Browser Smoke Addition

Extend runner verification/verify-browser-runner.mjs after the existing Runner cases. The implemented helper routes to Workbench, waits for Monaco to mount, drives a dedicated source test hook, runs the current buffer, and verifies the edited source changes the solved result. 

async function verifyWorkbenchRun(cdp) {
  await clickRoute(cdp, "workbench");
  await waitForSelector(cdp, "[data-workbench-page]");

  await evaluate(cdp, `(() => {
    const input = document.querySelector("[data-workbench-source-test-input]");
    const setter = Object.getOwnPropertyDescriptor(window.HTMLTextAreaElement.prototype, "value").set;
    setter.call(input, \`
include "heat_transfer_lib"
h := 100 [W/m^2*K]
A_c := 0.5
T_fluid := 20 [degC]
Q := 2 [kW]
NewtonCooling(h, A_c, T_surface, T_fluid, Q)
\`);
    input.dispatchEvent(new Event("input", { bubbles: true }));
  })()`);

  await click(cdp, "[data-workbench-run-button]");
  await waitForText(cdp, "T_surface");

  const result = await evaluate(cdp, `(() => document.body.innerText)()`);
  if (!/T_surface/.test(result) || !/60/.test(result)) {
    throw new Error("Workbench did not run edited source buffer.");
  }
}
Smoke detail

If Monaco is not exposed on window in the test page, drive the editor through DOM events or add a test-only data hook in MonacoSourceEditor. Do not skip workbench smoke because Monaco is harder to automate than a textarea.

Acceptance Checklist

  • Monaco loads inside the workbench and is visibly the source editor.
  • Run executes the current Monaco buffer without requiring a second file upload.
  • Structured results and raw output update from the same run result.
  • Workbench browser smoke proves the edited buffer is the primary path.
  • No worker message shape, runArgv, thisProgram, or CoNES core behavior changes.
  • Public Vercel URL passes hosted browser smoke after push.
