Packet 006A

Editor Shell

Packet 006A adds the first local authoring surface: load a .cnes file, edit text in the browser, and download the current draft. Running from editor is intentionally outside this packet.

Integrated locally No Monaco yet No diagnostics yet No run-from-editor yet

Scope

Included

A route-backed editor surface with .cnes upload, text editing, dirty state, source statistics, file metadata, new draft, and save/download as .cnes.

Excluded

This packet does not call the worker, alter runtime contracts, add Monaco, run lints, or introduce project folders.

Implementation

Component Path Notes
Editor page src/features/editor/EditorShellPage.tsx Owns file read, textarea state, metadata, dirty state, and download blob creation.
Feature export src/features/editor/index.ts Exposes the page for parent route integration.
App route src/app/routes.ts and src/app/App.tsx Parent integration adds the Editor route without changing Runner behavior.

Acceptance Checks

  • Opening a .cnes file populates the editor.
  • Editing updates dirty state and line/character counts.
  • Save downloads the current text as a .cnes file.
  • Non-.cnes input is rejected locally.
Human review needed

The page is ready for workflow review, especially text density, save wording, and whether the later run-from-editor integration should live in Runner or Editor.
