Packet 005

Results Viewer

Packet 005 turns the accepted --json output into a structured results surface while keeping raw stdout, stderr, exit code, and JSON download available as the source of truth.

Implemented Verified locally Deployed No runtime argument changes Raw output preserved

Goal

User Outcome

After running a .cnes file, users can scan variables, values, units, fixed/solved state, performance, and parser failures without reading raw JSON first.

Engineering Boundary

The viewer reads the existing worker result. It does not change callMain(["/work/input.cnes", "--json"]), mutate CoNES output, or hide raw stdout and stderr.

Delivered Components

Component Path Result
Structured viewer src/features/results/ResultsViewer.tsx Displays solver success, variable rows, units, fixed/solved state, performance, and parser/runtime summaries.
Runner integration src/features/runner/RunnerPage.tsx Mounts the structured viewer above raw output so the readable pane and raw artifacts coexist.
Browser smoke runner verification/verify-browser-runner.mjs Adds assertions for rendered result rows and invalid-parser summary behavior.
